# DESIGN SYSTEM — SAHARA CLUB

## COLORS

- Black: #0B0B0B
- Gold: #C6A76A
- Beige: #E8DCC8
- White: #FFFFFF

---

## TYPOGRAPHY

- Titles: Serif elegante
- Body: Sans-serif limpia

---

## UI PRINCIPLES

- Mucho espacio en blanco
- Animaciones suaves
- Nada saturado
- Jerarquía clara

---

## COMPONENTS

### Buttons
- Bordes redondeados
- Gold o outline

### Cards
- Fondo oscuro o beige
- Sombra suave
- Bordes 16-24px

### Inputs
- Minimalistas
- Sin bordes pesados

---

## UX RULE

Todo debe sentirse como un ritual, no como un sistema.

---

## ANTI-PATTERNS

- Colores brillantes
- UI saturada
- demasiados elementos
